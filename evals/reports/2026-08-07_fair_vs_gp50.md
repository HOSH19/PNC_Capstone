# Fair backtest vs Ming `gp50_fixed_v1` (post-audit fixes)

Date: 2026-08-07. Owner: Shu Han.

## Issues addressed

| Issue | Fix |
|---|---|
| Train labels peeking into test (~10%) | **366-day embargo**: train only `quarter_end_date ≤ 2020-12-30` |
| Unclosed label tails (2025H2–2026Q1 forced to 0) | Drop last 4 panel quarters after labeling (167,872 rows; matches Ming panel size) |
| `dep_outflow_soft` `fillna(0)` | Clip only; **NaNs preserved** |
| Ming GP duplicate keys (cert 32541) | `evals/backtest.py` keeps first row per `(cert, date)` |
| Label-adjacent features | **Kept** — same policy as Ming’s delivered GP (fair parity) |
| Apples-to-oranges row sets | Primary table = **intersected** test keys |

Embargo sanity: **8,209 train positives, 0** depend on a post-split event.

Protocol test window unchanged: `2021-12-31 < date ≤ 2024-12-31`,
labels [`evals/items/distress_bank_quarter_full.csv`](../items/distress_bank_quarter_full.csv).

**Note on Ming’s training cut:** his delivered backtest scores train through
~2021Q3 (prediction time ≤ split). Ours are stricter (embargo through
2020-12-30), so we use **less** near-boundary train data. A win under that
handicap is conservative vs his CSV.

## Verdict

1. After embargo + closed labels + dedupe, **HGB/XGB still beat Ming’s GP on
   PR-AUC** (~3.10× vs 3.00× lift) on identical test keys.
2. **GP remains best at precision@50** (top of the list).
3. Linear ratios remain a weak but positive baseline (~1.6× lift).
